Architecture & Technical Overview

This web application was engineered for the Procucev AI Tech Hiring Assignment. It provides an end-to-end real-time speech-to-text service optimized for multilingual environments, specifically code-switching between Hindi and English (Hinglish), backed by a persistent relational database and full CRUD dashboard.

1. Multilingual Audio Engine

  • Hybrid Web Speech API with sub-second interim streaming.
  • Google Gemini Live 3.1 Multimodal Audio API integration.
  • Heuristic & Unicode code-mixing ratio calculation (Hindi % vs English %).
  • Automatic punctuation, grammar, and script standardization.

2. Relational Database & Spring Data JPA

  • Persistent H2 relational file storage for instant zero-config run.
  • PostgreSQL profile ready for production/cloud deployment.
  • Indexed search, pagination, multi-column sorting, and analytics aggregation.
  • H2 Web Console available at /h2-console.

3. Real-Time WebSocket Streaming

  • Bidirectional WebSocket handler mounted at /ws/transcribe.
  • Real-time telemetry streaming for word counts, speaking rate (WPM), and language ratio.
  • Continuous connection heartbeat and auto-reconnect.

4. Text-To-Speech (TTS) & Export

  • Speech synthesis playback directly from the studio or any history card.
  • Multi-format export: JSON, CSV (Excel), Plain Text (TXT), and Subtitles (SRT).
  • Audio file dropzone accepting WAV, MP3, WebM, and OGG.

REST API Endpoints Reference

Method Endpoint Description
GET /api/transcriptions Fetch paginated list with search, language filter, and sort
POST /api/transcriptions Create a new transcription record
PUT /api/transcriptions/{id} Update transcription title, text content, notes, or tags
PATCH /api/transcriptions/{id}/favorite Toggle starred / favorite state
DELETE /api/transcriptions/{id} Delete single transcription record
GET /api/transcriptions/stats Get dashboard analytics (total count, words, language distribution)
GET /api/transcriptions/export?format=json|csv|txt|srt Export all transcriptions in selected format
POST /api/speech/transcribe-audio Upload audio file and transcribe via Gemini / backend engine
POST /api/speech/polish Refine Hinglish text (grammar, Devanagari, Romanized, translation)
